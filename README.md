# ColleagueConnect

**iOS Internship Case Study | n11**

ColleagueConnect is a native iOS application developed as part of an iOS internship case study. It provides a user directory experience powered by the GitHub API, allowing users to discover profiles, manage favorites, and revisit previously viewed users.

## Features

- **GitHub OAuth Authentication** — Sign in using GitHub.
- **User Search** — Search for GitHub users and explore their profiles.
- **User Profiles** — View profile information, including usernames, biographies, and avatars.
- **Favorites** — Save and manage favorite users.
- **Recently Viewed** — Quickly revisit previously opened profiles.
- **Sorting and Filtering** — Organize user lists.
- **Connectivity Handling** — Display connection feedback and support retrying requests.
- **Custom UI** — A consistent interface built programmatically with UIKit.

## Tech Stack

- Swift
- UIKit
- VIPER Architecture
- GitHub REST API
- OAuth Authentication
- Keychain
- URLSession
- Swift Concurrency (async/await)
- XCTest
- Git & GitHub

## Architecture

The application follows the VIPER architectural pattern to separate presentation logic, business logic, navigation, and data responsibilities.

The project also uses protocol-oriented abstractions and dependency injection to improve modularity, maintainability, and testability.
